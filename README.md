# Tushar Gautam Portfolio (GitHub Pages)

Futuristic founder portfolio for VidyaLok with enhanced GitHub REST API visualization, resume access, and preserved social links.

## Features

- GitHub REST API dashboard: caching, skeleton loaders, search, language filter, pinned spotlight, activity feed, push-derived heatmap.
- Resume download via `Tushar Gautam Resume.pdf`.
- Social icons preserved in the footer with upgraded motion styling.
- SEO metadata, Open Graph/Twitter tags, and JSON-LD Person schema in `index.html`.

## Local preview

Open `index.html` in a browser or serve the folder with any static server.

## Deploy

Push to the `main` branch of the GitHub Pages repository; the site serves `index.html` from the repo root.
